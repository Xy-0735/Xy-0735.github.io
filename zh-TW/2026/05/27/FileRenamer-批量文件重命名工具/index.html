FileRenamer：一款精緻強大的桌面端批次檔案重新命名工具

專案簡介

靈感來自於日常工作中頻繁需要整理大量檔案——照片、文件、素材等雜亂無章的檔名讓人頭疼，市面上雖有一些重新命名工具，但功能要麼單一，要麼介面老舊複雜。於是我動手打造了這款兼具顏值與實力的批次檔名更改工具。

解決的問題

在日常辦公與檔案管理中，批次檔案重新命名是一個高頻卻常被低估的需求痛點。攝影師從相機匯出的 DSC_0001.JPG 需要按日期和場景重新命名；開發者為專案資源檔新增統一的前綴後綴；運營人員整理活動素材時需要統一編號；追劇黨下載的劇集檔名雜亂難以管理……

面對這類需求，傳統方案的操作體驗往往令人沮喪。在 Windows 系統中，使用者只能使用系統內建的重新命名功能——選取多個檔案後右鍵重新命名，只能得到 檔案名稱 (1).ext 這樣呆板的格式，無法自訂起始序號、無法控制補零位數。更進階的需求則需要使用者編寫腳本（Python/Batch/PowerShell），不僅需要程式設計基礎，還要記憶複雜的字串處理語法和正規表達式。而 macOS 使用者雖然擁有 Finder 的原生批次重新命名功能，但規則有限且互動體驗一般。

市面上也有一些第三方重新命名工具，但普遍存在以下問題：介面設計停留在 Windows XP 時代；規則設定複雜、學習曲線陡峭；缺乏預覽功能，使用者不敢放心執行；不支援復原操作，一步誤操作後悔莫及。

核心矛盾：使用者對「靈活批次重新命名」的高頻需求，與現有方案「操作門檻高、功能簡陋、體驗落後」的現實形成尖銳對立。

這種「需求與供給」的巨大鴻溝，正是 FileRenamer 致力於填補的——讓每位使用者都能以最低的成本、最直觀的方式完成批次檔案重新命名。

核心價值

FileRenamer 不是在重複造輪子，而是對「批次重新命名」這一基礎工具進行了重新思考。其核心價值可從功能、體驗、安全三大維度展開。

功能廣度：9 種命名規則一站覆蓋

FileRenamer 內建了 9 種命名規則，覆蓋了批次重新命名中的絕大多數場景：序號命名（自訂起始值、補零位數、步長）、尋找與取代（快速批次修正檔名中的錯別字或多餘字元）、前綴/後綴（為檔名批次新增標籤）、刪除文字（移除檔名中的固定片段）、大小寫轉換（統一檔名格式）、正則取代（用 JavaScript 正規表達式實現進階配對和取代，支援擷取群組）、日期命名（以當前時間或檔案修改日期命名）、插入文字（在檔名指定位置插入字元）、副檔名修改（一鍵統一檔案格式後綴）。

多種規則可組合使用，滿足從「給旅行照片加上日期前綴」到「按正規表達式重新命名專案素材」的全場景需求。

體驗設計：所見即所得的桌面應用

FileRenamer 採用 Electron 桌面應用形態，提供原生視窗體驗的同時保持 Web 技術的靈活美觀。支援從檔案管理員直接拖曳檔案/資料夾到視窗，也支援透過對話框新增。檔案列表支援按檔名、修改日期、建立日期、大小、類型排序，多選與全選操作便捷。右鍵選單可快速重新命名單個檔案或移除。執行前可即時預覽所有重新命名結果，自動檢測檔名衝突並以紅色高亮標記。

安全兜底：復原 + 衝突檢測雙保險

批次重新命名是高風險操作——一旦出錯，可能毀掉整個專案檔案結構。FileRenamer 提供了復原功能，可復原最近一次批次重新命名。執行前自動檢測目標檔案是否已存在，存在則跳過並提示衝突。此外支援將重新命名對應關係匯出為 CSV 對照表，便於追溯和審計。

核心價值速覽

  • 9 種規則：序號、尋找取代、前後綴、刪除、大小寫、正則、日期、插入、副檔名
  • 拖曳操作：從檔案管理員直接拖入，預覽即所得
  • 安全保護：復原 + 衝突檢測 + CSV 匯出，不丟一個檔案
  • 跨平台：基於 Electron，Windows/macOS/Linux 均可執行
  • 開源免費：MIT 協議，程式碼公開，社群共建

無論是需要批次整理照片的攝影師，還是管理專案資源檔的開發者，FileRenamer 都以「功能全面-操作直觀-安全可靠」的產品設計，重新定義了批次重新命名工具的體驗標準。

功能特性

檔案管理：不止於重新命名

使用者與工具的第一步互動是匯入檔案。FileRenamer 在檔案管理層面做了細緻的打磨：拖曳新增——從檔案管理員直接將檔案或資料夾拖入視窗即可完成匯入，操作直覺化；檔案/資料夾匯入——透過對話框可新增單個檔案、多個檔案或整個資料夾，自動遞迴讀取資料夾內所有檔案；排序能力——支援按檔名、修改日期、建立日期、檔案大小、檔案類型五種維度排序，快速找到目標檔案；多選與全選——勾選或一鍵全選，僅對選中的檔案執行操作；右鍵選單——右鍵檔案可快速執行重新命名或移除操作；重複檢測——自動過濾已新增的檔案路徑，避免重複匯入導致命名衝突。

這些互動細節看似微小，卻構成了從「能用」到「好用」的關鍵躍遷。

9 種命名規則詳解

FileRenamer 的核心引擎是一套靈活的命名規則系統，每種規則都經過精心設計，平衡了靈活性、易用性和效能：

規則 功能說明
序號 支援自訂格式 {n}，可設定起始值、補零位數（如 001~999）、步長（間隔遞增）。適合照片編號、文件排序等場景
尋找與取代 尋找檔名中的文字並取代為指定內容，支援區分大小寫。適合批次修正拼寫錯誤或統一名詞
前綴/後綴 在檔名首部或尾部新增文字，支援序號變數 {n}。適合為專案檔案新增統一標籤
刪除文字 刪除檔名中的指定文字，支援全部刪除、僅刪除開頭、僅刪除結尾三種模式。適合去除下載檔案中的廣告前綴
大小寫轉換 支援全小寫、全大寫、首字母大寫，可設定轉換範圍（整個檔名、僅副檔名等）。適合統一檔案命名規範
正則取代 使用 JavaScript 正規表達式進行配對取代，支援擷取群組 $1 $2。適合複雜模式的批次替換
日期命名 以當前日期時間或檔案自身的修改/建立日期進行命名，支援 YYYY-MM-DD、YYYYMMDD_HHmmss 等自訂格式
插入文字 在檔名的指定位置（從第N個字元處）插入文字。適合在固定位置新增識別碼
副檔名修改 批次修改檔案副檔名，如將所有 .jpeg 統一改為 .jpg

安全機制：讓每一步都可逆

批次重新命名最大的恐懼來自於「不可逆」。FileRenamer 透過三層安全機制消除使用者的顧慮：

  1. 即時預覽：在規則設定介面即可看到所有檔案重新命名後的結果，未確認前不做任何實際修改。自動檢測目標檔名是否已存在，衝突檔案以紅色高亮標註，使用者可自行調整規則或移除衝突項。

  2. 一鍵復原：執行重新命名後，可透過 Ctrl+Z 或介面按鈕復原最近一次批次操作，所有重新命名的檔案會恢復到原來的檔名。復原機制基於操作歷史堆疊，支援完整還原。

  3. CSV 對照匯出：將重新命名前後的檔名、檔案路徑等對應關係匯出為 CSV 檔案。這不僅作為操作記錄的備份憑證，也方便使用者在必要時手動恢復或稽核批次操作的結果。

輕量級與效能

FileRenamer 的核心程式碼量極簡——主處理程序（main.js）、預載入腳本（preload.js）和渲染處理程序（app.js / styles.css / index.html）構成了整個應用，無額外框架依賴，全部使用原生 JavaScript 編寫。應用啟動迅速，檔案掃描和重新命名操作直接呼叫 Node.js 的 fs 模組，I/O 效率高。打包後的 Windows 可攜版體積小巧，無需安裝即可雙擊執行。

專案總結

一句話定位——FileRenamer 是一款基於 Electron 開發的跨平台桌面端批次檔案重新命名工具，內建 9 種命名規則，以「所見即所得」的預覽式互動和完整的安全兜底機制，讓批次重新命名變得簡單、安全、高效。

技術層面，專案採用 Electron + 原生 JavaScript 的極簡技術堆疊，無框架依賴，程式碼結構清晰。主處理程序負責檔案 I/O 和系統對話框，透過 IPC 與渲染處理程序通訊，預載入腳本在保證安全性的前提下暴露有限的 Node.js API。這種分層架構既保證了桌面應用的效能優勢，又充分利用了 Web 技術靈活美觀的 UI 表現力。

體驗設計上，專案聚焦「操作直覺化」與「安全可逆」兩大核心理念。從拖曳匯入到規則設定再到預覽執行，每一步都追求最低的認知負擔。9 種命名規則覆蓋了從簡單的前後綴新增到複雜的正規表達式取代的全場景需求，同時透過復原和衝突檢測機制確保批次操作萬無一失。

生態建構方面，專案以 MIT 協議開源，程式碼全程公開可審計。基於 Electron 的跨平台特性，理論上可擴充至 macOS 和 Linux 平台。開發者可基於現有架構輕鬆擴充自訂命名規則或整合其他檔案管理功能，社群共建潛力廣闊。

適用場景推薦

在日常工作與生活中，批次檔案重新命名是許多人頻繁遇到的需求。以下針對不同使用者群體的適用場景分析：

對於攝影師和設計師而言，從相機/素材庫匯出的檔案通常是毫無辨識度的編號，FileRenamer 的日期命名和序號規則可快速將 DSC_0001.JPG 批次轉換為 2026-05-27_東京旅拍_001.jpg 這樣有意義的檔名。

開發者在管理專案檔案時，常需要為資源檔批次新增前綴、統一擴充格式或按編號重排。FileRenamer 的正規取代和尋找取代規則可以在一秒內完成整個目錄下數百個檔案的重新命名，大幅提升專案標準化效率。

運營人員和內容創作者經常需要整理活動素材、影片素材、文件資料。FileRenamer 的拖曳匯入和多選操作非常契合這類「整理-命名-歸檔」的工作流程，從雜亂到有序只需幾分鐘。

普通使用者在日常使用中，下載的電視劇集、音樂檔案、電子書等常常帶有網站前綴或雜亂命名。透過尋找取代和刪除文字規則，一鍵即可清理所有多餘字元，讓檔案管理回歸清爽。

從專業創作到日常整理，FileRenamer 透過 9 種規則的靈活組合與直觀的預覽操作，為不同使用者群體解決了檔案管理中的重新命名痛點，讓檔案操作更優雅、更高效。
