個人項目

項目背景

隨著AI工具和API平台爆發式增長，開發者與用戶面臨一個共同的痛點：找工具難，比價更難。國內外上百款AI產品散落在各個角落，每次需要用的時候都要重新搜索、對比、試錯。

於是我決定做一個一站式AI導航頁，把主流AI工具和API平台整合到一個頁面裏，支持分類篩選、關鍵詞搜索、費用/訪問方式過濾，讓找工具這件事變得簡單。

構建思路

技術方案

純 HTML + CSS + JavaScript 單文件實現，零外部依賴，一個文件即可運行。

核心設計

  1. 雙Tab架構：頁面頂部設置"🛠️ AI工具集"和"⚡ API平台"兩個大Tab，切換時篩選器和數據網格同步切換，搜索框在兩個Tab間共享
  2. 三維篩選系統：
    • 類型維度：文本/編程/圖像/視頻/音頻/搜索/智能體/3D/辦公（工具集）；文本生成/代碼生成/圖像生成/嵌入向量化/聚合路由等（API平台）
    • 費用維度：免費 / 部分免費 / 付費
    • 訪問維度：國內直連 / 需魔法 / 部分受限
  3. 卡片式布局：每張卡片包含名稱、emoji圖標、所屬公司、簡介、類型標簽、費用標簽、訪問方式標簽，以及官網/文檔跳轉按鈕
  4. 實時搜索：支持按名稱、公司名模糊搜索，搜索結果實時更新
  5. 篩選器可折叠：點擊頂部篩選器按鈕可收起/展開，不遮擋內容瀏覽

UI設計

配色方案

采用雜誌風+自然系配色，避免"AI味"的藍紫漸變：

  • 主色調：森林綠 #2d5a47 + 琥珀金 #d4a574
  • 輔助色：珊瑚紅 #e07a5f
  • 背景：暖白 #faf9f7
  • 卡片：純白 #ffffff + 柔和陰影

標簽色系

標簽類型 配色 示例
免費 綠底綠字 #e8f5e9 / #2e7d32
部分免費 藍底藍字 #e3f2fd / #1565c0
付費 黃底橙字 #fff8e1 / #f57f17
國內直連 綠底綠字 #e8f5e9 / #2e7d32
需魔法 藍底藍字 #e8eaf6 / #3949ab
部分受限 橙底橙字 #fff3e0 / #e65100

交互細節

  • 卡片hover時微上移 + 陰影加深
  • 篩選按鈕點擊時active態變色
  • 返回頂部按鈕滾動超過一定距離自動出現
  • 篩選器sticky固定在header下方，滾動時始終可操作
  • 移動端適配：篩選器橫滑、卡片單列

特色亮點

1. 工具與API雙視角

同一個AI產品，普通用戶關心的是"能不能直接用"（工具視角），開發者關心的是"能不能調API"（平台視角）。雙Tab設計讓兩類用戶各取所需。

2. 訪問方式標注

每款工具都標注了是否需要科學上網，這對國內用戶來說是剛需信息。很多導航站不標注這一點，用戶點進去才發現訪問不了。

3. 費用透明

免費/部分免費/付費一目了然，避免用戶注冊半天才發現要付費。

4. API平台獨立分區

API平台區額外提供"📖 文檔"按鈕，直達官方API文檔，開發者不用再單獨搜索文檔地址。
