🔧 從零開始：用Hexo搭建專業博客及多平台部署全指南

📋 目錄

  1. Hexo環境搭建
  2. 創建並配置基礎博客
  3. 主題更換與個性化
  4. 部署到GitHub Pages
  5. 通過Netlify優化國內訪問
  6. 常見問題與解決方案

1. Hexo環境搭建

1.1 必備工具安裝

Hexo基於Node.js運行，需要先安裝以下工具：

  • Node.js（v14.0.0+）：提供運行環境
  • Git：用於版本控制和部署

驗證安裝是否成功

打開終端（Windows：CMD/PowerShell；Mac/Linux：Terminal），輸入以下命令：

檢查Node.js版本

node -v

示例輸出：v16.14.2

檢查npm版本（Node.js自帶）

npm -v

示例輸出：8.5.0

檢查Git版本

git --version
示例輸出：git version 2.34.1
若命令均能正常輸出版本號，則表示環境準備完成。

1.2 安裝Hexo腳手架

使用npm全局安裝Hexo命令行工具：

全局安裝Hexo

npm install -g hexo-cli

驗證安裝

hexo -v

示例輸出：hexo-cli: 4.3.0 …

2. 創建並配置基礎博客

2.1 初始化博客項目

創建博客目錄並初始化

hexo init my-hexo-blog

進入博客目錄

cd my-hexo-blog

安裝依賴包

npm install
執行完成後，博客目錄結構如下：
my-hexo-blog/
├── _config.yml # 全局配置文件
├── package.json # 項目依賴配置
├── source/ # 源文件目錄
│ └── _posts/ # 博客文章存放處
└── themes/ # 主題目錄

2.2 基本操作命令

新建一篇文章

hexo new “我的第一篇Hexo博客”

會在source/_posts目錄下生成對應的Markdown文件

生成靜態網頁

hexo generate # 可簡寫為 hexo g

啟動本地服務器預覽

hexo server # 可簡寫為 hexo s

默認訪問地址：

http://localhost:4000

清理緩存文件

hexo clean # 部署前建議執行，避免緩存導致的問題
啟動服務後，打開瀏覽器訪問 http://localhost:4000 即可看到默認主題的博客頁面。

2.3 全局配置修改

編輯根目錄下的 _config.yml 文件（建議使用VS Code等編輯器），修改基礎信息：

Site

title: 我的技術博客 # 博客標題
subtitle: 分享技術與生活 # 副標題
description: 這是我的個人博客 # 博客描述（用於SEO）
author: 張三 # 作者名
language: zh-CN # 語言（中文）
timezone: Asia/Shanghai # 時區（上海）

URL

url: https://yourname.github.io # 博客最終訪問地址
root: / # 根目錄
修改後保存，執行 hexo s 重啟服務即可看到變化。

3. 主題更換與個性化

Hexo默認主題為landscape，我們可以更換為更美觀的主題，這裏以熱門的Butterfly主題為例。

3.1 安裝Butterfly主題

克隆主題到themes目錄

git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly

3.2 啟用主題

修改根目錄 _config.yml 中的主題配置：

找到theme配置項，修改為butterfly

theme: butterfly

3.3 主題配置優化

為了避免主題升級時覆蓋自定義配置，建議使用獨立配置文件：

復制主題配置文件到根目錄

cp themes/butterfly/_config.yml _config.butterfly.yml
編輯 _config.butterfly.yml 進行個性化設置：

3.3.1 配置導航菜單

menu:
首頁: / || fa fa-home
歸檔: /archives/ || fa fa-archive
標簽: /tags/ || fa fa-tags
分類: /categories/ || fa fa-folder-open
關於: /about/ || fa fa-user

3.3.2 設置社交鏈接

social:
Github: https://github.com/yourname || fa fa-github
知乎: https://zhihu.com/people/yourname || fa fa-book
郵箱: mailto:your@email.com || fa fa-envelope

3.3.3 配置網站圖標

favicon:
icon: /img/favicon.ico # 網站圖標路徑
apple_touch_icon: /img/apple-touch-icon.png # 蘋果設備圖標
設置完成後，需要在 source 目錄下創建 img 文件夾並放入對應的圖片文件。

3.4 安裝主題依賴

Butterfly主題需要額外依賴：

安裝必要插件

npm install hexo-renderer-pug hexo-renderer-stylus --save
執行 hexo clean && hexo s 查看效果。

4. 部署到GitHub Pages

GitHub Pages提供免費的靜態網站托管服務，適合展示博客。

4.1 準備GitHub倉庫

  1. 登錄GitHub賬號，點擊右上角 + 號，選擇 New repository
  2. 倉庫名稱必須為：用戶名.github.io（例如：octocat.github.io）
  3. 選擇 Public 公開倉庫
  4. 點擊 Create repository 完成創建

4.2 配置Hexo部署參數

  1. 安裝部署插件：
    npm install hexo-deployer-git --save
  2. 編輯根目錄 _config.yml，配置部署信息：
    deploy:
    type: git
    repo: https://github.com/你的用戶名/你的用戶名.github.io.git

例如：https://github.com/octocat/octocat.github.io.git

branch: main # 主分支（GitHub新倉庫默認分支為main）

4.3 部署博客

清理緩存

hexo clean

生成並部署

hexo g -d # 等同於 hexo generate && hexo deploy
首次部署會要求輸入GitHub賬號和密碼（或token），驗證通過後即可完成部署。

幾分鐘後，訪問 https://你的用戶名.github.io 即可看到你的博客。

5. 通過Netlify優化國內訪問

GitHub Pages在國內訪問速度較慢，使用Netlify可以顯著提升訪問速度。

5.1 注冊並連接倉庫

  1. 訪問 Netlify官網 注冊賬號（可使用GitHub賬號直接登錄）
  2. 登錄後點擊 New site from Git
  3. 選擇 GitHub，授權訪問你的博客倉庫
  4. 選擇你的博客倉庫（用戶名.github.io）

5.2 配置構建參數

在部署設置頁面，填寫：

  • Build command: hexo clean && hexo generate
  • Publish directory: public

點擊 Deploy site 開始部署，Netlify會自動執行構建命令並部署。

5.3 配置自定義域名（可選）

  1. 在Netlify站點控制台，點擊 Domain settings
  2. 點擊 Add custom domain，輸入你購買的域名（例如：blog.example.com）
  3. 在域名提供商的DNS管理界面，添加以下記錄：
    • 類型：CNAME
    • 主機記錄：blog（或@表示主域名）
    • 記錄值：你的Netlify子域名（例如：xxxxxx.netlify.app）

5.4 啟用HTTPS

Netlify會自動為你的域名配置SSL證書，在 Domain settings 中找到 HTTPS 選項，開啟強制HTTPS訪問。

6. 常見問題與解決方案

6.1 本地預覽樣式錯亂

1. 清理緩存並重新生成

hexo clean && hexo g

2. 檢查主題是否正確安裝

ls themes/butterfly # 應顯示主題文件

3. 確認依賴已安裝

npm list hexo-renderer-pug

6.2 部署後頁面空白

  • 檢查 _config.yml 中的 url 配置是否正確
  • 確認部署分支是否為 main 或 master
  • 查看部署日誌（GitHub Actions或Netlify構建日誌）排查錯誤

6.3 圖片無法顯示

  • 使用相對路徑引用圖片：![描述](img/圖片名.jpg)
  • 確保圖片放在 source/img 目錄下
  • 避免使用中文文件名，可能導致部署後無法訪問

6.4 國內訪問速度優化

  • 確保已通過Netlify部署
  • 圖片資源可使用阿裏雲OSS、七牛雲等國內CDN存儲
  • 禁用不必要的外部資源（如Google字體、國外評論系統）

🎉 總結

通過以上步驟，你已經成功搭建了一個基於Hexo的博客，並實現了多平台部署。後續只需專注於內容創作，通過以下命令發布新文章：

新建文章

hexo new “文章標題”

編輯完成後部署

hexo clean && hexo g -d
博客會自動同步到GitHub Pages和Netlify，國內外用戶都能快速訪問你的內容。
