FileRenamer: A Refined and Powerful Desktop Batch File Renaming Tool

Project Introduction

Inspired by the frequent need to organize large amounts of files in daily work — photos, documents, assets, and other files with messy names are a headache. While there are some renaming tools on the market, they are either feature-limited or have outdated, complex interfaces. So I built this batch file renaming tool that combines both aesthetics and power.

The Problem It Solves

In daily office work and file management, batch file renaming is a high-frequency yet often underestimated pain point. Photographers need to rename DSC_0001.JPG exports from their cameras by date and scene; developers add unified prefixes and suffixes to project resource files; operations personnel need unified numbering when organizing campaign materials; binge-watchers struggle with messy episode filenames that are hard to manage…

Faced with such needs, the operational experience of traditional solutions is often frustrating. In Windows, users can only use the built-in rename function — selecting multiple files and right-clicking rename only produces rigid formats like filename (1).ext, with no way to customize starting numbers or control zero-padding digits. More advanced needs require users to write scripts (Python/Batch/PowerShell), which demands not only programming foundations but also memorization of complex string manipulation syntax and regular expressions. macOS users, while having Finder’s native batch rename functionality, are limited by its fixed rules and mediocre interaction experience.

There are also some third-party renaming tools on the market, but they generally suffer from: interfaces stuck in the Windows XP era; complex rule configuration with steep learning curves; lack of preview functionality, leaving users afraid to execute with confidence; no undo support, making one misstep a source of lasting regret.

Core Contradiction: Users’ high-frequency need for “flexible batch renaming” stands in sharp opposition to the reality of existing solutions that have “high operational barriers, rudimentary functionality, and outdated user experience.”

This enormous gap between “demand and supply” is precisely what FileRenamer is committed to filling — enabling every user to complete batch file renaming at the lowest cost and in the most intuitive way.

Core Value

FileRenamer is not about reinventing the wheel, but about rethinking the fundamental tool of “batch renaming.” Its core value can be broken down into three dimensions: functionality, experience, and safety.

Functional Breadth: 9 Naming Rules Covering All Needs

FileRenamer comes with 9 built-in naming rules covering the vast majority of batch renaming scenarios: Sequential Numbering (customizable start value, zero-padding digits, step size), Find & Replace (quickly batch-correct typos or redundant characters in filenames), Prefix/Suffix (batch-add tags to filenames), Delete Text (remove fixed segments from filenames), Case Conversion (unify filename casing), Regex Replace (advanced matching and replacement using JavaScript regular expressions with capture group support), Date Naming (name using current time or file modification date), Insert Text (insert characters at a specified position in the filename), Extension Modification (batch-change file format suffixes).

Multiple rules can be combined to meet needs ranging from “adding date prefixes to travel photos” to “renaming project assets using regular expressions.”

Experience Design: WYSIWYG Desktop Application

FileRenamer adopts the Electron desktop application form, providing a native window experience while maintaining the flexibility and aesthetics of web technology. It supports direct drag-and-drop of files/folders from the file manager into the window, as well as adding files through dialogs. The file list supports sorting by filename, modification date, creation date, size, and type, with convenient multi-select and select-all operations. The right-click context menu allows quick renaming or removal of individual files. Before execution, users can preview all renaming results in real-time, with automatic detection of filename conflicts highlighted in red.

Safety Net: Undo + Conflict Detection Dual Protection

Batch renaming is a high-risk operation — one mistake could ruin an entire project’s file structure. FileRenamer provides an undo feature that can reverse the most recent batch rename. Before execution, it automatically detects whether target filenames already exist, skipping and flagging conflicts when found. Additionally, it supports exporting rename mappings as CSV files for traceability and auditing.

Core Value at a Glance

  • 9 Rules: Sequential numbering, find & replace, prefix/suffix, deletion, case conversion, regex, date, insertion, extension
  • Drag & Drop: Drag directly from file manager, preview as you configure
  • Safety Protection: Undo + conflict detection + CSV export — not a single file lost
  • Cross-Platform: Built on Electron, runs on Windows/macOS/Linux
  • Open Source & Free: MIT license, public code, community-driven

Whether for photographers needing to batch-organize photos or developers managing project resource files, FileRenamer redefines the experience standard for batch renaming tools through its “comprehensive functionality — intuitive operation — safe and reliable” product design.

Features

File Management: More Than Just Renaming

The first interaction between user and tool is importing files. FileRenamer has been meticulously polished at the file management level: Drag & Drop Import — directly drag files or folders from the file manager into the window for intuitive importing; File/Folder Import — add single files, multiple files, or entire folders through dialogs, automatically reading all files within folders recursively; Sorting Capabilities — sort by five dimensions: filename, modification date, creation date, file size, and file type, to quickly find target files; Multi-Select & Select All — check or select all with one click, only applying operations to selected files; Right-Click Menu — right-click a file to quickly rename or remove it; Duplicate Detection — automatically filter out already-added file paths to prevent naming conflicts from duplicate imports.

These interaction details may seem minor, but they constitute the critical leap from “usable” to “delightful.”

9 Naming Rules in Detail

FileRenamer’s core engine is a flexible naming rule system, with each rule carefully designed to balance flexibility, usability, and performance:

Rule Description
Sequential Numbering Supports custom format {n}, with configurable start value, zero-padding digits (e.g., 001~999), and step size (interval increment). Ideal for photo numbering, document sorting, etc.
Find & Replace Find text in filenames and replace with specified content, with case-sensitive option. Ideal for batch-correcting spelling errors or unifying terminology
Prefix/Suffix Add text at the beginning or end of filenames, supporting the sequence variable {n}. Ideal for adding unified labels to project files
Delete Text Delete specified text from filenames, supporting three modes: delete all, delete from start only, delete from end only. Ideal for removing ad prefixes from downloaded files
Case Conversion Supports lowercase, uppercase, and title case, with configurable scope (entire filename, extension only, etc.). Ideal for unifying file naming conventions
Regex Replace Match and replace using JavaScript regular expressions, with capture group support ($1, $2). Ideal for complex pattern-based batch replacement
Date Naming Name files using current date/time or the file’s own modification/creation date, supporting custom formats like YYYY-MM-DD, YYYYMMDD_HHmmss
Insert Text Insert text at a specified position (by character index) in the filename. Ideal for adding identifiers at fixed positions
Extension Modification Batch-modify file extensions, e.g., converting all .jpeg to .jpg

Safety Mechanisms: Making Every Step Reversible

The greatest fear in batch renaming comes from “irreversibility.” FileRenamer eliminates user concerns through a three-layer safety mechanism:

  1. Real-Time Preview: View all renaming results right in the rule configuration interface, with no actual modifications made until confirmed. Automatically detects whether target filenames already exist, highlighting conflicts in red so users can adjust rules or remove conflicting items.

  2. One-Click Undo: After executing a rename, press Ctrl+Z or use the interface button to undo the most recent batch operation, restoring all renamed files to their original filenames. The undo mechanism is based on an operation history stack, supporting complete rollback.

  3. CSV Mapping Export: Export the correspondence between original and new filenames, along with file paths, as a CSV file. This serves not only as a backup record of the operation but also makes it convenient for users to manually restore or audit batch operation results when needed.

Lightweight & Performance

FileRenamer’s core codebase is minimal — consisting of the main process (main.js), preload script (preload.js), and renderer process (app.js / styles.css / index.html), with no additional framework dependencies, all written in vanilla JavaScript. The application starts quickly, and file scanning and renaming operations directly call Node.js’s fs module for high I/O efficiency. The packaged Windows portable version is compact and can be run by double-clicking without installation.

Project Summary

One-Sentence Positioning — FileRenamer is a cross-platform desktop batch file renaming tool built on Electron, featuring 9 built-in naming rules. With WYSIWYG preview-based interaction and a complete safety net, it makes batch renaming simple, safe, and efficient.

On the technical front, the project adopts the minimalist tech stack of Electron + vanilla JavaScript with no framework dependencies and a clear code structure. The main process handles file I/O and system dialogs, communicating with the renderer process via IPC, while the preload script exposes limited Node.js APIs under the guarantee of security. This layered architecture preserves the performance advantages of desktop applications while fully leveraging the flexible and beautiful UI expressiveness of web technologies.

In experience design, the project focuses on the two core philosophies of “intuitive operation” and “safe reversibility.” From drag-and-drop import to rule configuration to preview execution, every step pursues the lowest cognitive burden. The 9 naming rules cover the full spectrum from simple prefix/suffix additions to complex regex replacements, while the undo and conflict detection mechanisms ensure batch operations are foolproof.

For ecosystem building, the project is open-sourced under the MIT license with fully public and auditable code. Leveraging Electron’s cross-platform nature, it can theoretically be extended to macOS and Linux platforms. Developers can easily extend custom naming rules or integrate other file management features based on the existing architecture, with vast potential for community collaboration.

Recommended Use Cases

In daily work and life, batch file renaming is a need many people frequently encounter. Below are use case analyses for different user groups:

For photographers and designers, files exported from cameras/asset libraries typically have meaningless serial numbers. FileRenamer’s date naming and sequential numbering rules can quickly batch-convert DSC_0001.JPG into meaningful filenames like 2026-05-27_Tokyo_Trip_001.jpg.

Developers managing project files often need to batch-add prefixes to resource files, unify extension formats, or renumber files. FileRenamer’s regex replace and find & replace rules can complete the renaming of hundreds of files in a directory within seconds, dramatically improving project standardization efficiency.

Operations personnel and content creators frequently need to organize campaign assets, video materials, and documents. FileRenamer’s drag-and-drop import and multi-select operations perfectly fit this “organize — name — archive” workflow, transforming chaos into order in just minutes.

Ordinary users, in daily use, often find that downloaded TV series episodes, music files, e-books, and other files come with website prefixes or messy names. Using the find & replace and delete text rules, all redundant characters can be cleaned up in one click, restoring refreshing file management.

From professional creation to daily organization, FileRenamer addresses the renaming pain points in file management for different user groups through the flexible combination of 9 rules and intuitive preview operations, making file operations more elegant and efficient.
