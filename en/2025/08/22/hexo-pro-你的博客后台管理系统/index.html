Developer Notes

This article references the open-source project [wuzheng228/hexo-pro] on GitHub (address: https://github.com/wuzheng228/hexo-pro).

Features

Core Advantages

  • 🚀 Extremely Easy to Use: Friendly interface, intuitive operation, zero learning curve to get started
  • 🌗 Multi-Theme Support: One-click toggle between dark and light modes, adapting to different usage scenarios
  • 📱 Mobile-Friendly: Responsive design, fully supporting phones, tablets, and PCs
  • 🔒 Safe and Reliable: Multi-user permission management, ensuring data security
  • ⚡ Efficient Integration: Seamless integration with the Hexo ecosystem, supporting mainstream plugins and themes

Feature Highlights

  • Article Management: Create, edit, and delete posts, with visual front-matter editing support
  • Page Management: Easily manage static pages
  • Image Hosting Integration: Supports paste-to-upload images and batch management
  • Configuration Management: Visual editing of Hexo configuration files
  • Global Search: Blazing-fast full-text search powered by Fuse.js
  • One-Click Deployment: Multiple deployment methods for easy publishing
  • Internationalization Support: Multi-language interface, friendly for users worldwide
  • Desktop-Exclusive Features: Multi-project management, automatic authentication, native menus, offline support, smart port management, and more
  • And much more…
