🔧 From Scratch: Building a Professional Blog with Hexo and Multi-Platform Deployment Guide

📋 Table of Contents

  1. Setting Up the Hexo Environment
  2. Creating and Configuring a Basic Blog
  3. Theme Change and Customization
  4. Deploying to GitHub Pages
  5. Optimizing Domestic Access via Netlify
  6. FAQ and Solutions

1. Setting Up the Hexo Environment

1.1 Installing Prerequisites

Hexo runs on Node.js. You need to install the following tools first:

  • Node.js (v14.0.0+): Provides the runtime environment
  • Git: Used for version control and deployment

Verifying the Installation

Open a terminal (Windows: CMD/PowerShell; Mac/Linux: Terminal) and run the following commands:

Check Node.js version

node -v

Example output: v16.14.2

Check npm version (bundled with Node.js)

npm -v

Example output: 8.5.0

Check Git version

git --version
Example output: git version 2.34.1
If all commands return version numbers, your environment is ready.

1.2 Installing the Hexo CLI

Install the Hexo command-line tool globally via npm:

Install Hexo globally

npm install -g hexo-cli

Verify installation

hexo -v

Example output: hexo-cli: 4.3.0 …

2. Creating and Configuring a Basic Blog

2.1 Initializing a Blog Project

Create a blog directory and initialize

hexo init my-hexo-blog

Enter the blog directory

cd my-hexo-blog

Install dependencies

npm install
After completion, the blog directory structure will look like this:
my-hexo-blog/
├── _config.yml # Global configuration file
├── package.json # Project dependency config
├── source/ # Source files directory
│ └── _posts/ # Blog posts storage
└── themes/ # Themes directory

2.2 Basic Operations

Create a new post

hexo new “My First Hexo Post”

A corresponding Markdown file will be generated under source/_posts

Generate static pages

hexo generate # shorthand: hexo g

Start local server for preview

hexo server # shorthand: hexo s

Default access URL:

http://localhost:4000

Clean cache files

hexo clean # Recommended before deployment to avoid cache issues
After starting the server, open your browser and visit http://localhost:4000 to see the blog with the default theme.

2.3 Modifying Global Configuration

Edit the _config.yml file in the root directory (recommended editors like VS Code) and update the basic info:

Site

title: My Tech Blog # Blog title
subtitle: Sharing Tech & Life # Subtitle
description: This is my personal blog # Blog description (for SEO)
author: John Doe # Author name
language: en # Language
timezone: Asia/Shanghai # Timezone (Shanghai)

URL

url: https://yourname.github.io # Final access URL for your blog
root: / # Root directory
Save changes, then run hexo s to restart the server and see the changes.

3. Theme Change and Customization

Hexo’s default theme is landscape. We can switch to a more polished theme. Let’s use the popular Butterfly theme as an example.

3.1 Installing the Butterfly Theme

Clone the theme into the themes directory

git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly

3.2 Enabling the Theme

Modify the _config.yml in the root directory:

Find the theme config item and change it to butterfly

theme: butterfly

3.3 Optimizing Theme Configuration

To avoid overwriting custom settings when upgrading the theme, use a separate config file:

Copy the theme config file to the root directory

cp themes/butterfly/_config.yml _config.butterfly.yml
Edit _config.butterfly.yml for personalization:

3.3.1 Configuring the Navigation Menu

menu:
Home: / || fa fa-home
Archives: /archives/ || fa fa-archive
Tags: /tags/ || fa fa-tags
Categories: /categories/ || fa fa-folder-open
About: /about/ || fa fa-user

3.3.2 Setting Up Social Links

social:
Github: https://github.com/yourname || fa fa-github
Zhihu: https://zhihu.com/people/yourname || fa fa-book
Email: mailto:your@email.com || fa fa-envelope

3.3.3 Configuring the Site Icon

favicon:
icon: /img/favicon.ico # Site icon path
apple_touch_icon: /img/apple-touch-icon.png # Apple device icon
After setup, create an img folder under the source directory and place the corresponding image files there.

3.4 Installing Theme Dependencies

The Butterfly theme requires additional dependencies:

Install necessary plugins

npm install hexo-renderer-pug hexo-renderer-stylus --save
Run hexo clean && hexo s to see the results.

4. Deploying to GitHub Pages

GitHub Pages offers free static website hosting, perfect for showcasing your blog.

4.1 Preparing the GitHub Repository

  1. Log in to your GitHub account, click the + icon in the top right, and select New repository
  2. The repository name must be: username.github.io (e.g., octocat.github.io)
  3. Select Public
  4. Click Create repository to finish

4.2 Configuring Hexo Deployment Parameters

  1. Install the deployment plugin:
    npm install hexo-deployer-git --save
  2. Edit the root _config.yml and configure deployment info:
    deploy:
    type: git
    repo: https://github.com/your-username/your-username.github.io.git

Example: https://github.com/octocat/octocat.github.io.git

branch: main # Main branch (default branch for new GitHub repos is main)

4.3 Deploying the Blog

Clean the cache

hexo clean

Generate and deploy

hexo g -d # Equivalent to hexo generate && hexo deploy
On the first deployment, you will be prompted for your GitHub username and password (or token). Once verified, deployment will complete.

After a few minutes, visit https://your-username.github.io to see your blog.

5. Optimizing Domestic Access via Netlify

GitHub Pages loads slowly in some regions. Using Netlify can significantly improve access speed.

5.1 Register and Connect Your Repository

  1. Visit the Netlify website to register (you can sign in directly with your GitHub account)
  2. After logging in, click New site from Git
  3. Choose GitHub and authorize access to your blog repository
  4. Select your blog repository (username.github.io)

5.2 Configuring Build Parameters

On the deployment settings page, fill in:

  • Build command: hexo clean && hexo generate
  • Publish directory: public

Click Deploy site to start deployment. Netlify will automatically run the build command and deploy.

5.3 Setting Up a Custom Domain (Optional)

  1. In the Netlify site dashboard, click Domain settings
  2. Click Add custom domain and enter your purchased domain (e.g., blog.example.com)
  3. In your domain provider’s DNS management panel, add the following record:
    • Type: CNAME
    • Host: blog (or @ for the root domain)
    • Value: your-netlify-subdomain (e.g., xxxxxx.netlify.app)

5.4 Enabling HTTPS

Netlify will automatically configure an SSL certificate for your domain. In Domain settings, find the HTTPS option and enable forced HTTPS.

6. FAQ and Solutions

6.1 Messed Up Styles in Local Preview

1. Clean cache and regenerate

hexo clean && hexo g

2. Check if the theme is installed correctly

ls themes/butterfly # Should display theme files

3. Confirm dependencies are installed

npm list hexo-renderer-pug

6.2 Blank Page After Deployment

  • Check whether the url in _config.yml is correct
  • Verify the deployment branch is main or master
  • Check deployment logs (GitHub Actions or Netlify build logs) for errors

6.3 Images Not Displaying

  • Use relative paths for images: ![description](img/image-name.jpg)
  • Make sure images are placed in the source/img directory
  • Avoid using non-ASCII characters in file names, as they may cause issues after deployment

6.4 Optimizing Access Speed in Some Regions

  • Make sure you have deployed through Netlify
  • Use CDN services (such as Alibaba Cloud OSS, Qiniu Cloud) for image assets
  • Disable unnecessary external resources (e.g., Google Fonts, foreign comment systems)

🎉 Summary

By following the steps above, you have successfully built a Hexo-powered blog with multi-platform deployment. From here, just focus on creating content and publish new posts with these commands:

Create a new post

hexo new “Post Title”

Deploy after editing

hexo clean && hexo g -d
Your blog will automatically sync to both GitHub Pages and Netlify, so visitors everywhere can quickly access your content.
