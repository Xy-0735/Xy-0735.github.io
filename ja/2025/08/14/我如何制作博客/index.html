🔧 ゼロから始める：Hexoでプロフェッショナルなブログを構築し、マルチプラットフォームにデプロイする完全ガイド

📋 目次

  1. Hexo環境の構築
  2. ブログの作成と基本設定
  3. テーマの変更とカスタマイズ
  4. GitHub Pagesへのデプロイ
  5. Netlifyで中国国内からのアクセスを最適化
  6. よくある問題と解決策

1. Hexo環境の構築

1.1 必須ツールのインストール

HexoはNode.js上で動作するため、以下のツールを先にインストールする必要があります：

  • Node.js（v14.0.0+）：実行環境を提供
  • Git：バージョン管理とデプロイに使用

インストールの確認

ターミナルを開き（Windows：CMD/PowerShell；Mac/Linux：Terminal）、以下のコマンドを入力してください：

Node.jsのバージョン確認

node -v

出力例：v16.14.2

npmのバージョン確認（Node.jsに同梱）

npm -v

出力例：8.5.0

Gitのバージョン確認

git --version
出力例：git version 2.34.1
すべてのコマンドが正常にバージョン番号を出力すれば、環境準備は完了です。

1.2 Hexo CLIのインストール

npmを使ってHexoコマンドラインツールをグローバルインストールします：

Hexoのグローバルインストール

npm install -g hexo-cli

インストールの確認

hexo -v

出力例：hexo-cli: 4.3.0 …

2. ブログの作成と基本設定

2.1 ブログプロジェクトの初期化

ブログディレクトリを作成して初期化

hexo init my-hexo-blog

ブログディレクトリに移動

cd my-hexo-blog

依存パッケージのインストール

npm install
実行後、ブログのディレクトリ構造は以下のようになります：
my-hexo-blog/
├── _config.yml # グローバル設定ファイル
├── package.json # プロジェクト依存関係の設定
├── source/ # ソースファイルディレクトリ
│ └── _posts/ # ブログ記事の保存場所
└── themes/ # テーマディレクトリ

2.2 基本操作コマンド

新しい記事を作成

hexo new “初めてのHexoブログ”

source/_postsディレクトリに対応するMarkdownファイルが生成されます

静的ページを生成

hexo generate # hexo g と省略可能

ローカルサーバーを起動してプレビュー

hexo server # hexo s と省略可能

デフォルトのアクセスアドレス：

http://localhost:4000

キャッシュファイルをクリア

hexo clean # デプロイ前に実行することを推奨、キャッシュによる問題を防止
サーバー起動後、ブラウザで http://localhost:4000 にアクセスすると、デフォルトテーマのブログページが表示されます。

2.3 グローバル設定の変更

ルートディレクトリの _config.yml ファイルを編集し（VS Codeなどのエディタを推奨）、基本情報を変更します：

Site

title: 私の技術ブログ # ブログタイトル
subtitle: 技術と生活を共有 # サブタイトル
description: これは私の個人ブログです # ブログ説明（SEO用）
author: 山田太郎 # 作者名
language: zh-CN # 言語（中国語）
timezone: Asia/Shanghai # タイムゾーン（上海）

URL

url: https://yourname.github.io # ブログの最終アクセスURL
root: / # ルートディレクトリ
変更を保存したら、hexo s を実行してサーバーを再起動すると変更が反映されます。

3. テーマの変更とカスタマイズ

Hexoのデフォルトテーマはlandscapeです。より美しいテーマに変更できます。ここでは人気のButterflyテーマを例に説明します。

3.1 Butterflyテーマのインストール

テーマをthemesディレクトリにクローン

git clone -b master https://github.com/jerryc127/hexo-theme-butterfly.git themes/butterfly

3.2 テーマの有効化

ルートディレクトリの _config.yml にあるテーマ設定を変更します：

theme設定項目を見つけて、butterflyに変更

theme: butterfly

3.3 テーマ設定の最適化

テーマのアップグレード時にカスタム設定が上書きされるのを防ぐため、独立した設定ファイルを使用することを推奨します：

テーマ設定ファイルをルートディレクトリにコピー

cp themes/butterfly/_config.yml _config.butterfly.yml
_config.butterfly.yml を編集してカスタマイズします：

3.3.1 ナビゲーションメニューの設定

menu:
ホーム: / || fa fa-home
アーカイブ: /archives/ || fa fa-archive
タグ: /tags/ || fa fa-tags
カテゴリ: /categories/ || fa fa-folder-open
概要: /about/ || fa fa-user

3.3.2 ソーシャルリンクの設定

social:
Github: https://github.com/yourname || fa fa-github
Zhihu: https://zhihu.com/people/yourname || fa fa-book
メール: mailto:your@email.com || fa fa-envelope

3.3.3 サイトアイコンの設定

favicon:
icon: /img/favicon.ico # サイトアイコンのパス
apple_touch_icon: /img/apple-touch-icon.png # Appleデバイス用アイコン
設定後、source ディレクトリに img フォルダを作成し、対応する画像ファイルを配置する必要があります。

3.4 テーマ依存関係のインストール

Butterflyテーマには追加の依存関係が必要です：

必要なプラグインをインストール

npm install hexo-renderer-pug hexo-renderer-stylus --save
hexo clean && hexo s を実行して効果を確認します。

4. GitHub Pagesへのデプロイ

GitHub Pagesは無料の静的サイトホスティングサービスで、ブログの公開に適しています。

4.1 GitHubリポジトリの準備

  1. GitHubアカウントにログインし、右上の + をクリックして New repository を選択
  2. リポジトリ名は必ず：ユーザー名.github.io にします（例：octocat.github.io）
  3. Public 公開リポジトリを選択
  4. Create repository をクリックして作成完了

4.2 Hexoデプロイパラメータの設定

  1. デプロイプラグインをインストール：
    npm install hexo-deployer-git --save
  2. ルートディレクトリの _config.yml を編集し、デプロイ情報を設定：
    deploy:
    type: git
    repo: https://github.com/あなたのユーザー名/あなたのユーザー名.github.io.git

例：https://github.com/octocat/octocat.github.io.git

branch: main # メインブランチ（GitHubの新しいリポジトリのデフォルトブランチはmain）

4.3 ブログのデプロイ

キャッシュをクリア

hexo clean

生成してデプロイ

hexo g -d # hexo generate && hexo deploy と同等
初回デプロイ時にはGitHubアカウントとパスワード（またはトークン）の入力が求められ、認証が通ればデプロイが完了します。

数分後、https://あなたのユーザー名.github.io にアクセスするとブログが表示されます。

5. Netlifyで中国国内からのアクセスを最適化

GitHub Pagesは中国国内でのアクセス速度が遅いため、Netlifyを使用するとアクセス速度を大幅に向上できます。

5.1 登録してリポジトリと連携

  1. Netlify公式サイト にアクセスしてアカウント登録（GitHubアカウントで直接ログイン可能）
  2. ログイン後、New site from Git をクリック
  3. GitHub を選択し、ブログリポジトリへのアクセスを認証
  4. ブログリポジトリ（ユーザー名.github.io）を選択

5.2 ビルドパラメータの設定

デプロイ設定ページで以下を入力：

  • Build command: hexo clean && hexo generate
  • Publish directory: public

Deploy site をクリックしてデプロイを開始すると、Netlifyが自動的にビルドコマンドを実行してデプロイします。

5.3 カスタムドメインの設定（任意）

  1. Netlifyサイトダッシュボードで Domain settings をクリック
  2. Add custom domain をクリックし、購入したドメイン（例：blog.example.com）を入力
  3. ドメインプロバイダのDNS管理画面で、以下のレコードを追加：
    • タイプ：CNAME
    • ホスト名：blog（または@はメインドメインを表す）
    • 値：あなたのNetlifyサブドメイン（例：xxxxxx.netlify.app）

5.4 HTTPSの有効化

Netlifyは自動的にドメインのSSL証明書を設定します。Domain settings で HTTPS オプションを見つけ、強制HTTPSアクセスを有効にします。

6. よくある問題と解決策

6.1 ローカルプレビューでスタイルが崩れる

1. キャッシュをクリアして再生成

hexo clean && hexo g

2. テーマが正しくインストールされているか確認

ls themes/butterfly # テーマファイルが表示されるはず

3. 依存関係がインストールされているか確認

npm list hexo-renderer-pug

6.2 デプロイ後にページが空白になる

  • _config.yml の url 設定が正しいか確認
  • デプロイブランチが main または master か確認
  • デプロイログ（GitHub ActionsまたはNetlifyビルドログ）でエラーを確認

6.3 画像が表示されない

  • 相対パスで画像を参照：![説明](img/画像名.jpg)
  • 画像が source/img ディレクトリにあることを確認
  • 中国語のファイル名を避ける（デプロイ後にアクセスできない場合があります）

6.4 中国国内でのアクセス速度最適化

  • Netlify経由でデプロイされていることを確認
  • 画像リソースにAlibaba Cloud OSS、Qiniu Cloudなどの国内CDNストレージを使用
  • 不要な外部リソース（Google Fonts、海外コメントシステムなど）を無効化

🎉 まとめ

以上の手順で、Hexoベースのブログを構築し、マルチプラットフォームデプロイを実現しました。あとはコンテンツ作成に集中し、以下のコマンドで新しい記事を公開するだけです：

新しい記事を作成

hexo new “記事タイトル”

編集完了後にデプロイ

hexo clean && hexo g -d
ブログは自動的にGitHub PagesとNetlifyに同期され、国内外のユーザーがあなたのコンテンツに素早くアクセスできるようになります。
